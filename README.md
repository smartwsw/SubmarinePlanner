# 潜水艇规划器

FF14 部队潜水艇的航点规划与收益估算工具。读取本机 AutoRetainer 配置，按掉落估值自动搜索航线。

- 在线试用：<https://smartwsw.github.io/SubmarinePlanner/>
- 本地运行：`node server.js`，然后打开 <http://127.0.0.1:4173>

## 功能

**潜艇配置**：从 AutoRetainer 读出等级与四件配件，按「等级 + 配件」合并同配潜艇；也可手动新增配置，存在浏览器本地。配件下拉用 AutoRetainer 的简写标注（中文 `1`–`5`/`1改`–`5改`，英文 `S/U/W/C/Y` 与 `S+/U+/W+/C+/Y+`）。属性卡片显示探索、收集、速度、航程、耐久、恩惠的合计与部件/等级来源，并附游戏内效果说明。

**航点规划**：按海域列出航点，含需求等级、解锁前置、调查耗时、经验、青磷水消耗和掉落估值。勾选航点后汇总航程占用、总耗时、经验与净收益。航程按 AutoRetainer 的算法核算，超限的点位置灰禁用。

**路线生成**：在当前海域枚举 1~5 个点位的组合与顺序，按「掉落估值 / 小时」打分，优先落在 24/48/72 小时整数倍前 35 分钟内。

**收益估算**：掉落池按探索值解锁，每个已解锁的池各抽一次，恩惠达标后翻倍（整趟上限 4 次）。单池估值 = `概率 × 数量区间中点 × 单价` 之和，数量档由收集值决定。单价来自 Universalis 国服，优先取近期成交均价，无成交时用挂牌价中位数。

**成本扣减**：按 AutoRetainer 的耐久公式计算每趟的修理材料消耗（四部件 `(335 + 航点等级 − 部件 rank) × 7` 取最大值，30000 点耐久摊到可跑趟数），按魔导修理材料市价折算后从收益中扣除。

**价格缓存**：价格不会自动过期，存在浏览器本地。需要更新时点「重新获取价格」，下方显示上次更新时间。只有从没查过的物品和切换服务器后会重新请求。

**低成交量提醒**：掉落卡片的大区日成交量低于 5 件时边框标红，并标出具体成交量。成交量是 Universalis 的 `regularSaleVelocity`，按整个大区统计、不是单个服务器。这只影响显示，估值仍按市场价计算——卖得慢不等于不值钱。

## 托管说明

`server.js` 是本机运行时才需要的：它负责读 AutoRetainer 配置、代理 Universalis 价格。部署到 GitHub Pages 时这些都不存在，页面会进入静态模式——使用内置的示例潜艇（可在界面上改成自己的配置），价格直接向 Universalis 查询（其接口允许跨域）。静态模式下读不到本机配置，这是浏览器沙箱的限制，无法绕过。

## 已知限制

- 配置里只有当前航线，没有「已解锁航点」列表，因此按等级判断可达性，未按实际探索进度过滤。
- 海域最后一点需要打通上一海域的解锁链，当前未跨海域展开完整链路；部分航点依赖额外条件，AutoRetainer 用哨兵值 `9876` 表示「条件未知」。
- 恩惠「未达阈值时有概率多拿一件」没有公开概率数据（Argus 的 `ItemYield.cs` 明确不建模），所以只按阈值建模。
- 掉落概率来自玩家众包航行记录，样本量有限；游戏单次只抽一件，实际收入会高于或低于估值。
- 单价低于 10,000 gil 的物品（原木、矿石、晶簇等）计入掉落但不计收益，避免廉价原料摊薄估值；沉船首饰（22500–22507）只能卖店，按 `Price{Low}` 计价且不受该门槛限制。
- 周期约束受可选航点限制：高级航点单点调查就超过 10 小时，严格 24 小时可能只剩 1~2 个停点。

## 数据来源

航点/海域/配件名称与数值取自游戏数据表（`SubmarineExploration`、`SubmarinePart`、`SubmarineRank`）及其国服中文版；解锁关系取自 AutoRetainer `Unlocks.cs`；掉落池取自 Argus `LootTable.json`（源头为 FFXIVGachaSpreadsheet 众包记录），阈值取自 SubmarineTracker；价格来自 Universalis。
